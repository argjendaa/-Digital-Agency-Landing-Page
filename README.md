# Digital Agency Landing Page

## Përshkrimi i Projektit

Digital Agency Landing Page është një website modern dhe responsive i krijuar për agjenci digjitale, studio kreative, freelancerë dhe kompani teknologjike. Projekti fokusohet në prezantimin e shërbimeve, projekteve të realizuara, informacioneve të kompanisë dhe mënyrave të kontaktit në një mënyrë profesionale dhe vizualisht tërheqëse.

Ky projekt është ndërtuar duke përdorur HTML, CSS dhe JavaScript dhe shërben si projekt Front-End për portfolio, duke demonstruar aftësitë në dizajn responsive, zhvillim të ndërfaqes së përdoruesit (UI) dhe implementim të funksionaliteteve interaktive.

# Digital Agency Landing Page

## Project Overview

Digital Agency Landing Page is a modern and responsive website designed for digital agencies, creative studios, freelancers, and technology companies. The project focuses on presenting services, portfolio projects, company information, and contact details in a professional and visually appealing way.

This project is built using HTML, CSS, and JavaScript and serves as a Front-End portfolio project to demonstrate responsive web design, user interface development, and interactive website functionality.
